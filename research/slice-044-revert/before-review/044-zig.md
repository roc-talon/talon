# 044 Zig

Phase: P1. Status: review

Slice 044 is the Zig dependency of a source build (CLI 6.6, R-D1 to R-D4): where Talon finds a Zig that fits a commit, how it installs one from the Zig index with the sha256 check, the dependency list, and its prompt. There is no command in this slice: `tln roc install --git` is slice 045, which reads `build.zig.zon` of the source (`Zig.minimum`) and then calls `ZigInstall.ensure!`. The L2 entry `zig` and the test tool `flowprobe zig` are the stand-ins. It follows `docs/agents/BRIEF-tests.md`. The pre-slice copies of the changed files are in `research/slice-044-revert/before/` (with `NEW.txt`).

Size (TW19): the private reference has about 405 lines of code (without comments and blank lines): `Zig.roc` 230 (pure), `ZigInstall.roc` 173 (the command part), plus about 25 lines in `Consent.roc`. The plan row says 300. No module has more than 450 lines (`Zig.roc` has 376 with its doc), so no split is needed.

The live index was read on 2026-10-25 (`https://ziglang.org/download/index.json`, 83 KB) to check the shape that the fixtures copy: the keys `master` (with `version`) and `0.17.0`, `0.16.0`, ...; for each release `date`, `notes`, `src`, `bootstrap` and one object for each target (`x86_64-linux`, `aarch64-macos`, `x86_64-windows`, ...) with `tarball`, `shasum` and `size` (a text of digits). The Windows archives are `.zip`, the others `.tar.xz`. Not checked (no 54 MB download): the top dir of an archive, `zig-<target>-<version>/`, as the older releases have it.

## 6. Decisions that the design does not fix (the test agent chose, for review)

| # | Decision | Rejected |

| D1 | `ensure!` is a function with the need as a text. No command in this slice: 045 calls it. L2 entry `zig` and `flowprobe zig` are the test stand-ins | A hidden command. Waiting for 045 (the rules R-D1 to R-D4 are 044) |

| D5 | The consent comes before the lock. A `xz` check, the downloader choice and all environment errors come after the consent and under the lock, before the first file (as `Download.choose` in slice 021) | The `xz` check before the prompt |
| D6 | `.tar.xz` and `.zip` are extracted by the same `tar -xf <archive> -C <temp> --strip-components=1` line (slice 021 D1). `xz` is needed on Linux only | A separate `xz -d` step |
| D7 | The archive is downloaded into the temp dir and deleted after `tar`. `.talon.json` is written last, then the rename (R-CC4 step 6). Failures of tar and a wrong sha256 are `Integrity` (exit 16), curl is `Network` (15), as slice 021 D9 | |

| D10 | An installed Zig is a dir `zig-<X.Y.Z>`. A dev version, a temp dir, a lock dir and a trash dir are not Zig. Its version is the dir name: no `zig version` job | Run `zig version` for each installed dir |
